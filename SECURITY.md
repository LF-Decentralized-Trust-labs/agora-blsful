# Security Policy

## Reporting a Security Bug

If you think you have discovered a security issue in the code, I'd like to hear from you. I take all security bugs seriously. If an issue is confirmed, I will patch it within a reasonable amount of time and release a public security bulletin that discusses its impact and credits the discoverer.

The best and easiest way to report a security bug is to email the author a description of the flaw and any related information, such as reproduction steps and the affected version.
